## Authenticated server equipment

Practice 0.14 pins equipment rules separately from unchanged practice 0.13 and immutable weapon hashes. Each equipment snapshot binds the authenticated wallet, actor, exact local chain, collection, token, build and asset nonce. The real wallet login session is bound to the socket origin and is never returned in Journey snapshots. Free or development soldier entitlement remains distinct from gun ownership.

Magazine, reserve, cadence and reload now resolve the admitted weapon, preserving class damage and reload modifiers, armour and abilities. State validation checks deployed actors, exact equipment identity and ammunition limits. Equipment snapshots have their own canonical hash and durable admission record. Migration seven reserves each gun for one active run and commits that allocation with run and progress entry creation. A failed entry write rolls everything back and allows a new verified retry. Recovery from disk requires both the run credential and the matching authenticated wallet.

The checked adapter verifies ownership before fresh commands, ticks and active resume. Transfer, listing and cancellation advance an asset nonce. Transfer away and back therefore cannot revive an old equipment snapshot. A confirmed greater nonce can admit the current owner and permanently revoke the earlier run. Quitting that old run cannot free the newer run's allocation. No new onchain gun transfer lock is implied by the soldier lease approval.

Ten equipment application cases cover exact identity parsing, version compatibility, admitted cadence, reload, damage, range, walls, armour and brace, class focus boundaries, tamper rejection, atomic rollback, duplicate admission, replay, disk recovery and nonce revocation. Two figure cases check the existing class figures and explicit equipped gun selection while retaining their class silhouettes. The actual disposable chain cases log in through HTTP using local wallet signatures, start Journey over real sockets, fire exactly once across a retry, reconnect with unchanged equipment and ammunition, and verify that transfer stops fresh commands and ticks for both marksman and support builds. Transfer back still rejects stale resume. Initial NFT claims are authored fixtures; this does not prove gameplay earned issuance, browser wallet UI or owned NFT soldier admission.
